## Constat important
Dans Odoo, les données de formation sont stockées sur le contact (onglet "formation"). Dans la nouvelle application, elles sont réparties ainsi (hypothèse à valider) :
- Contact (stagiaire) -> MissionParticipant
- Centre -> client de la mission (Partner organisme)
- Intitulé, Type, Logiciel, Durée, Tarif, Fournir_PC, Enregistrer -> TrainingMission
- Dossier créé / 1er appel / Planif / Facture envoyée -> statut et checklist de la mission
- fiche detail -> Document rattaché à la mission

## Réponses (2026-11-18)
- Type = type de formation : distance / présentiel, et individuel / en groupe -> deux champs : modality et group_format.
- OS : PC ou Mac.
- Logiciel : AutoCAD, Revit, Fusion, SolidWorks, ... -> liste de référence modifiable dans Paramètres.
- Status : terminé / en cours (avancement de la formation du stagiaire) -> statut du participant.

## Implémentation (lot 2, 2026-11-18)
Retenu : type (particulier / entreprise / organisme), nom, prénom, société de rattachement (recherche),
fonction, rôles client / prospect / stagiaire, n° client automatique CLI-00001 (attribué au passage en client),
email, téléphone, mobile, site web, étiquettes (création à la volée), adresse, SIREN, SIRET, TVA, DUNS,
notes internes, contacts associés (+ ajout d'un interlocuteur), notes datées, historique champ par champ.
Actions : dupliquer, archiver / désarchiver, supprimer (refusé si des contacts sont rattachés ou si le contact
est utilisé ailleurs).
Différé : onglet "formation" (lot 3b, missions), compteurs Facturé / Documents (lots 5 et 3b).
Non retenu : Ventes, Abonnements, Tickets, Mandats de prélèvement, WhatsApp, enrichissement automatique.
Hypothèse : client et prospect sont exclusifs ; le statut stagiaire est un rôle cumulable.
